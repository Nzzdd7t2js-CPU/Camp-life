# 風餐露宿 CAMP LIFE｜角色與資料權限驗收表

狀態：測試計畫；尚未代表 Supabase 線上環境已通過測試。

## 1. 認領申請

| 測試身分 | 操作 | 預期結果 |
|---|---|---|
| 未登入訪客 | 送出認領 | 前端要求登入；資料庫不得接受匿名 INSERT |
| 一般會員 A | 建立認領 | 只可建立自己的申請；只能寫入 user_id、營區資料、聯絡說明、驗證方式與管道 |
| 一般會員 A | 讀取自己的申請 | 可讀取自己的申請與狀態 |
| 一般會員 A | 讀取會員 B 的申請 | RLS 拒絕或回傳空結果 |
| 一般會員 A | 自行寫入 status、reviewed_by、verification_status、verification_note | 欄位權限拒絕 |
| 一般會員 A | 呼叫 set_claim_verification | RPC 拒絕：只有網站業主可以設定 |
| 營主 | 認領另一個未認領營區 | 仍需先經網站業主核實及核准，不因已有營主角色自動通過 |
| 網站業主 | 設定 verified 但未提供管道或核對依據 | RPC 拒絕 |
| 網站業主 | 未核實就呼叫核准 | RPC 拒絕 |
| 網站業主 | 核實後核准未被認領的營區 | 原子更新營區 owner、會員角色、申請狀態並寫入稽核紀錄 |
| 網站業主 | 核准已由其他帳號認領的營區 | RPC 拒絕，不得覆蓋原營主 |

## 2. 營區管理

| 測試身分 | 操作 | 預期結果 |
|---|---|---|
| 一般會員 | 直接修改 campsites | RLS／GRANT 拒絕 |
| 營主 A | 讀取自己認領的營區 | 僅取得 owner_user_id 綁定自己的營區 |
| 營主 A | 修改營主允許的電話、價格欄位 | 只能透過受限 RPC 更新允許欄位 |
| 營主 A | 修改營區名稱、地址、owner_user_id 或其他非授權欄位 | 不得成功 |
| 營主 A | 修改營主 B 的營區 | RPC 拒絕 |
| 網站業主 | 管理營區資料 | 依業主權限執行，操作需保留紀錄 |

## 3. 會員資料

| 測試身分 | 操作 | 預期結果 |
|---|---|---|
| 一般會員 A | 讀取自己的 profile | 可讀取自己的會員資料 |
| 一般會員 A | 讀取會員 B 的 Email／profile | RLS 拒絕或回傳空結果 |
| 一般會員 A | 修改自己的 display_name | 可成功 |
| 一般會員 A | 修改自己的 role 或 Email | 欄位權限拒絕 |
| 營主 | 讀取其他會員資料 | 不可因營主角色取得額外會員個資權限 |
| 網站業主 | 搜尋會員管理資料 | 僅在管理後台可讀取必要欄位 |

## 4. 日誌、評論、裝備與照片

- 未登入訪客只能讀取公開內容。
- 會員只能新增自己的內容，不能偽造其他 user_id。
- 未公開內容只可由作者本人及網站業主讀取。
- 一般會員不能任意核准或隱藏其他人的內容。
- camp-journal-photos 目前為公開讀取用途；不得把認領證明、身分證或其他私密文件放進這個 bucket。
- 若未來需要收取敏感附件，必須另建 private bucket、限制下載權限並設保存期限；目前尚未建立。

## 5. 上線前測試記錄

每項測試都要記錄：測試日期、使用角色、操作、實際結果、錯誤訊息／截圖、是否符合預期。不得只以「按鈕被隱藏」判定安全；必須確認資料庫 RLS、欄位 GRANT 與 RPC 也拒絕未授權操作。

## 6. 尚未完成／不可宣稱完成

- 認領驗證目前設計為網站業主人工核實；尚未串接 Email、簡訊、DNS 或社群平台自動驗證。
- 新增的 SQL migration 尚未在 Supabase 正式環境執行。
- 新認領表單與業主核實操作尚未在 Cloudflare 線上網站部署及實測。
- 會員／營主／業主權限測試尚未完成。
- 隱私權政策、個資告知、資料保存期限及爭議處理規則仍需台灣法律專業人士審閱。
